# 만들 게임 목록

만들었으면 하는 게임을 "대기"에 한 줄로 적어두세요. 게임 스튜디오가 위에서부터 차례로 만들어요.
대기 목록이 비어 있거나 남은 게 다 만들어졌으면 기획 에이전트가 직접 아이디어를 정해요.

- 적는 예: `- [ ] 떨어지는 반찬을 도시락에 받는 게임. 손가락으로 좌우 이동, 1분 타임어택`
- 만든 아이디어는 그 게임의 `game.json`에 `"idea"`로 기록돼서 다시 만들지 않아요. 목록은 원할 때 직접 정리하면 돼요.
- 게임 PR끼리 부딪히지 않게, 에이전트는 이 파일을 고치지 않아요.

## 대기

- [ ] 떨어지는 반찬을 도시락통으로 받는 게임. 좌우 이동, 상한 반찬은 피하기
- [ ] 한 번 탭으로 점프하는 끝없는 달리기. 지붕 위를 달리는 고양이(새 캐릭터)
- [ ] 같은 색 블록 3개 이상 이어서 터뜨리는 짧은 퍼즐. 60초 제한
- [ ] 박자에 맞춰 화면을 탭하는 리듬 게임. 음악은 Web Audio로 직접 만든 짧은 루프
- [ ] 바람을 보고 종이비행기를 멀리 날리는 게임. 각도·힘 조절
- [ ] 숫자 1부터 순서대로 빨리 누르는 집중력 게임. 기록이 짧을수록 좋음
- [ ] 미로에서 열쇠를 모아 나가는 짧은 퍼즐. 스테이지 5개

# 만들 게임 목록

만들었으면 하는 게임을 "대기"에 한 줄로 적어두세요. 게임 스튜디오가 위에서부터 차례로 만들어요.
대기 목록이 비어 있거나 남은 게 다 만들어졌으면 기획 에이전트가 직접 아이디어를 정해요.

- 적는 예: `- [ ] 떨어지는 반찬을 도시락에 받는 게임. 손가락으로 좌우 이동, 1분 타임어택`
- 만든 아이디어는 그 게임의 `game.json`에 `"idea"`로 기록돼서 다시 만들지 않아요. 목록은 원할 때 직접 정리하면 돼요.
- 게임 PR끼리 부딪히지 않게, 에이전트는 이 파일을 고치지 않아요.
- 공식 게임은 옛 플래시 게임 포털(점심먹고노라라·야후꾸러기·쥬니어네이버)에서 인기 있던 장르를 빌려 만들어요. 괄호 속 "참고"는 장르를 알려주는 것일 뿐, 이름·캐릭터·그림은 새로 만들어요.

## 대기

- [ ] 분식집 운영: 손님 주문표대로 라면을 끓여 내는 게임. 물 붓기·면 넣기·토핑 순서와 익는 시간 맞추기, 하루 영업 2분 (참고: 슈의 라면가게, Papa's Pizzeria)
- [ ] 선생님이 칠판을 보는 동안만 몰래 춤추는 게임. 누르고 있으면 춤추며 점수, 선생님이 돌아보기 전에 손 떼기 (참고: 선생님 안볼때 춤추기)
- [ ] 누르는 동안 떠오르고 떼면 내려가는 원버튼 비행. 점점 좁아지는 동굴에서 오래 버티기 (참고: Helicopter Game)
- [ ] 크레인에 매달려 흔들리는 층을 타이밍 맞춰 떨어뜨려 아파트를 높이 쌓는 게임 (참고: Tower Bloxx)
- [ ] 한 화면짜리 방에서 물건을 눌러 단서를 모으고 문을 여는 방탈출. 방 3개 (참고: 아이탈출, 감옥탈출)
- [ ] 불판 위 꼬치를 알맞게 구워 손님에게 내는 게임. 덜 익거나 타지 않게 뒤집기 (참고: 고기굽기 야키니쿠정)
- [ ] 튀어 다니는 공을 위로 쏘는 줄로 맞혀 작게 쪼개 없애는 아케이드. 좌우 이동 + 쏘기 (참고: Bubble Struggle)
- [ ] 둘이 하는 배구. 점프로 공 넘기기, 키보드는 한 대로 둘이·휴대폰은 화면 좌우 반쪽, 혼자면 컴퓨터와 (참고: 피카츄 배구, 1대1 축구)
- [ ] 3분 동안 먹이 주기·씻기기·놀아주기로 병아리를 닭으로 키우는 게임 (참고: 병아리 키우기)
- [ ] 떨어지는 반찬을 도시락통으로 받는 게임. 좌우 이동, 상한 반찬은 피하기
- [ ] 한 번 탭으로 점프하는 끝없는 달리기. 지붕 위를 달리는 고양이(새 캐릭터)
- [ ] 같은 색 블록 3개 이상 이어서 터뜨리는 짧은 퍼즐. 60초 제한
- [ ] 박자에 맞춰 화면을 탭하는 리듬 게임. 음악은 Web Audio로 직접 만든 짧은 루프
- [ ] 바람을 보고 종이비행기를 멀리 날리는 게임. 각도·힘 조절
- [ ] 숫자 1부터 순서대로 빨리 누르는 집중력 게임. 기록이 짧을수록 좋음
- [ ] 미로에서 열쇠를 모아 나가는 짧은 퍼즐. 스테이지 5개

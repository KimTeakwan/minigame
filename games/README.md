# 공식 게임 (운영팀 AI 제작)

이 폴더의 게임은 운영팀 에이전트가 만들어요. 흐름은 이래요.

1. 매일 예약 작업이 `.claude/routines/game-studio.md`대로 게임을 1개 만들어요 (기획 → 제작 → 검수).
2. 검수를 통과하면 `game-<이름>-<날짜>` 브랜치로 PR을 열어요. PR에 스크린샷과 바로 플레이해볼 수 있는 링크가 있어요.
3. 소유자가 PR에서 플레이해보고 **Merge**하면, GitHub Actions(`공식 게임 올리기`)가 공식 계정으로 사이트에 업로드해요.
4. 업로드된 게임은 일반 업로드와 똑같이 검수 워커(`npm run worker`)를 거쳐 공개돼요.

고쳐줬으면 하는 점은 PR에 댓글로 남기면 다음 예약 작업 때 반영해요. 마음에 안 드는 게임은 PR을 **Close**하면 돼요.
만들었으면 하는 게임은 `IDEAS.md`의 "대기" 목록에 한 줄로 적어두세요. 위에서부터 차례로 만들어요.

## 폴더 구조

```
games/
  <slug>/            영어 소문자와 하이픈 (예: lunchbox-tower)
    index.html       게임 전체 (CSS·JS·그림·소리 모두 이 파일 안에)
    game.json        사이트에 들어갈 게임 정보
    thumbnail.png    썸네일 (검사 스크립트가 플레이 화면을 찍어서 만들어요, 800×600)
  _template/         새 게임 뼈대 (밑줄로 시작하는 폴더는 사이트에 안 올라가요)
  IDEAS.md           만들 게임 목록
```

## game.json

```json
{
  "title": "도시락 탑 쌓기",
  "description": "사이트 게임 페이지에 보이는 소개 (2~4문장, 해요체)",
  "howto": "조작법과 규칙 (해요체)",
  "category": "캐주얼",
  "tags": ["쌓기", "원터치"],
  "controls": "both",
  "leaderboard": true,
  "score_order": "desc",
  "ai_tool": "Claude",
  "idea": "IDEAS.md에서 고른 줄 그대로 (직접 정한 아이디어면 이 항목은 빼요)"
}
```

| 항목 | 규칙 |
|---|---|
| `title` | 1~60자. 유명 게임·캐릭터·브랜드 이름 금지 |
| `description` | 2000자 이하 (실제로는 2~4문장) |
| `howto` | 1000자 이하 |
| `category` | `액션` `퍼즐` `캐주얼` `아케이드` `리듬` `스포츠` `기타` 중 하나 |
| `tags` | 최대 10개, 각 20자 이하 |
| `controls` | `both`(키보드·터치) 기본. 키보드 없이는 안 되는 게임만 `keyboard` |
| `leaderboard` | 점수가 있는 게임이면 `true` |
| `score_order` | 높을수록 좋으면 `desc`, 낮을수록 좋으면(시간 기록 등) `asc` |
| `ai_tool` | 항상 `"Claude"` |
| `idea` | 선택. `IDEAS.md`에서 고른 아이디어면 `- [ ] ` 뒤의 글을 그대로 적어요. 사이트에는 안 올라가요 |

## 게임 규칙 (검사 스크립트가 확인해요)

**파일**
- `index.html` 한 파일에 전부 넣어요. 1MB 이하.
- 외부 주소 접속 금지: CDN, 웹폰트, 외부 이미지·소리, `fetch` 모두 안 돼요. 그림은 캔버스로 그리거나 인라인 SVG, 소리는 Web Audio로 직접 만들어요.
- 글꼴은 시스템 글꼴만 써요 (`_template`의 font-family 그대로).

**사이트 iframe 안에서 돌아가야 해요** (`sandbox="allow-scripts allow-pointer-lock"`, 별도 도메인)
- `localStorage`, `sessionStorage`, `indexedDB`, 쿠키를 쓰면 오류가 나요. 최고 점수는 변수에만 저장해요.
- `alert`, `confirm`, `prompt`, `window.open`은 막혀 있어요. 화면 안에 직접 그려요.
- 바깥 페이지(`top`, `parent`)를 건드리지 않아요. 전체화면 버튼은 사이트가 따로 갖고 있어요.

**리더보드**
- `leaderboard: true`면 `_template`에 들어 있는 SDK 코드를 그대로 두고, 게임이 끝날 때 `GameSDK.submitScore(점수)`를 한 번, 다시 시작할 때 `GameSDK.newRound()`를 불러요.

**화면과 조작**
- 창 크기를 꽉 채우고 크기가 바뀌면 다시 맞춰요. 320×480(작은 휴대폰 세로)부터 1280×800(PC)까지, 가로·세로 모두 스크롤바 없이 보여야 해요.
- 키보드와 터치 둘 다 돼요 (`controls: "both"`). 터치는 탭·좌우 반쪽 누르기·화면 버튼처럼 휴대폰에서 바로 되는 방식으로 해요.
- 화면 흐름: 시작 화면(제목, 조작법 한 줄, "탭하거나 스페이스를 눌러 시작") → 플레이 → 게임 오버(점수, 최고 점수, 다시 하기).
- 한 판은 30초~3분 정도로 해요.
- 소리는 첫 입력 뒤에 켜지고, 화면 구석에 음소거 버튼이 있어요.

**내용 (전체이용가)**
- 피·잔인한 표현, 선정적인 내용, 도박(확률형 뽑기 포함), 실존 인물, 남의 캐릭터·브랜드는 넣지 않아요.
- 장르는 자유롭게 빌려와도 되지만 이름·그림·캐릭터는 새로 만들어요.
- 화면 글자는 한국어 해요체로 써요.

## 품질 기준 (검수 에이전트가 봐요)

- 처음 10초 안에 뭘 해야 하는지 알 수 있어요.
- 조작하면 바로 반응해요 (효과음, 작은 파티클, 화면 흔들림 같은 손맛).
- 처음엔 쉽고 점점 어려워져요. 억울하게 죽는 판정이 없어요.
- 휴대폰에서 손가락이 중요한 부분을 가리지 않아요. 글자가 너무 작지 않아요 (최소 14px).
- 보통 휴대폰에서도 부드럽게 돌아가요 (요소 수 관리, 매 프레임 큰 메모리 할당 피하기).

## 직접 검사해보기

```bash
node scripts/check-game.mjs games/<slug>
```

실제 브라우저로 사이트와 같은 조건(별도 도메인 + sandbox iframe)에서 켜보고, PC와 휴대폰 크기에서 조작해본 뒤 결과를 알려줘요. 통과하면 `thumbnail.png`도 새로 찍어요.
Playwright가 필요해요. 없으면 `npm i -g playwright && npx playwright install chromium`으로 설치해요.
